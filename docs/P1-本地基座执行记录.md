## 配置实现

- `app/core/settings.py` 独立定义全部 80 项，不在运行时读取设计 Markdown/候选 JSON。配置覆盖和数值默认值由测试对照设计/候选验证，避免静默漂移。
- 严格正数/非负、有限值、枚举/布尔、URL/健康路径、列表、管理员 Key、CA/时区/CIDR、入口容量/池/清理/停止/健康过期等静态交叉约束已实现。锁定 Python tzdata 直接加载 UTC、Asia/Shanghai，不依赖系统 tzdb。
- `app/core/config.py` 只读取明确选定的一个文件，不执行变量插值。默认 development/test 读取 `.env`；company 显式使用公司配置，不回退、不混读开发文件。具体地址、数据库名和账号由文件/同名进程变量提供，应用不绑定现场值。
- CLI 和进程选择冲突、文件重复/未知字段、错误类型均被拒绝。开发环境误指正式库或非 DeepSeek 上游由唯一 CLI 的 `app.config_check --profile local-development` 拒绝；应用不再通过硬编码地址猜测环境。列表用 JSON 数组，布尔仅 true/false。APP_ENV/APP_ENV_FILE/MIGRATION 等是工程选择/工具输入，不改变 80 项运行配置源表。
- 三个敏感运行字段使用 SecretStr；配置 CLI 仅输出环境/校验状态和固定字段/规则标识。原始 ValidationError 输入不能直接日志化。
- 当前 `.env` 校验通过；现有 `.env.company` 健康路径仍待确认，校验失败是预期，未填猜测值或关闭校验绕过。
- 没有创建 FastAPI app、API 路由、真实鉴权/转发/健康任务或生产启动器。配置模型不能替代这些后续实现，也不证明现场资源满足门槛。

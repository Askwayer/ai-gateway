## 3. 现场命令与证据规则

新增脚本 [p0_preflight.py](../scripts/p0_preflight.py) 的 host 模式只依赖 Python 标准库。将仓库工作文件送至目标机后，在项目目录执行（示例文件名应改成实际 UTC 时间戳；父目录须先存在）：

```bash
mkdir -p .tools/p0-evidence
/usr/bin/python3 scripts/p0_preflight.py host --require-target --output .tools/p0-evidence/target-host-YYYYMMDDTHHMMSSZ.json
```

脚本检查 Ubuntu 24.04、x86_64、Python >=3.12.3,<3.13，记录 CPU/内存/磁盘、系统 Python 包及 timedatectl 状态。NTP 服务未安装、未同步或无法读取时仍需人工补证；`collected` 只表示采集成功，不表示全部现场条件通过。额外记录 chrony/等效校时的源与偏差、容器/宿主资源配额、服务管理器及真实停止时限。

数据库模式使用环境变量 DATABASE_URL，未设置时读取 `--env-file` 指定文件（默认 `.env`）。文件只支持字面 `KEY=VALUE`，不执行 shell，不展开变量；不要把 DSN 放在命令行参数中：

```bash
.venv/bin/python scripts/p0_preflight.py database --output .tools/p0-evidence/database-YYYYMMDDTHHMMSSZ.json
```

JSON 证据文件以 0600 创建且禁止覆盖。使用不同时间戳复测；不要删除失败记录只保留成功记录。`.tools` 已忽略，不提交密码、真实提示词或未经审查的响应。需要归档时先审查脱敏，再将报告和 SHA-256 清单复制到受控交付目录。签收记录必须能定位所用设计/锁/脚本版本、执行主机、时间、profile、结果和证据哈希。
